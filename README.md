# 🚗 Pink Pixel Racer

A cute and fast retro 2D arcade racing game built with pure HTML, CSS, and JavaScript! Avoid the blue enemy cars, pick your difficulty using the traffic light menu, and go for the highest score possible.

---

## 🎮 How to Play

1. **Choose your difficulty:** Select **Easy** (Green), **Medium** (Orange), or **Hardcore** (Red) from the traffic light menu.
2. **Controls:**
   * **Left Arrow / A:** Steer left
   * **Right Arrow / D:** Steer right
3. **Objective:** Stay on the road and dodge incoming blue cars. The longer you survive, the faster the game gets!

---

## 🛠️ Built With

* **HTML5** – Game layout & UI menus
* **CSS3** – Custom styling for the track, cars, and traffic light buttons
* **JavaScript (Vanilla)** – Game loop, movement physics, and collision detection
